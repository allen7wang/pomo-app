## 共同业务功能

| 模块 | 对齐标准 |
|---|---|
| 番茄计时 | 启动、暂停、继续、显式放弃、跳到休息；暂停不计失败，放弃/跳过不算完成，也不增加 combo；阶段沿用启动时的业务配置，跨日恢复按原期限归档且不自动创造新专注 |
| 休息 | 短休息、长休息、手动/自动开始；1/5/15/30 分钟自选休息仅限空闲且保留已有 combo；延长为 0 不按超时处理；暂停休息再继续不能错误完成一个番茄 |
| 时长设置 | 番茄 1–120 分钟、短休息 1–60 分钟、长休息 1–120 分钟、延长 0–30 分钟、combo 1–12 个 |
| 时间块 | 1–24 块，每块 1–12 个番茄；分钟 0–59、午夜端点、跨午夜时段，起止相等按全天；目标、块任务、标题修改、完成/确认删除及预计番茄数；当前块定位 |
| 时间块奖励 | 达标仅记录/奖励一次，不因超过目标或重复恢复而重复计分；支持开始前提醒、冲刺提醒、提前分钟配置和休息建议 |
| 种植 | 完成一个 Pomo 种灌木，放弃/跳过记枯萎；combo 另种树，空槽保留；与每日块进度分文件存储 |
| Task | Work/MyOwn 各最多新增 3 条，Chores 无上限；新增、修改标题、完成/取消、确认删除、分类改名、昨日只读及未完成任务顺延 |
| Task 云同步 | 创建/编辑/完成/删除对应 Habitica todo，分类对应 tag；仅导入严格应用日期/分类备注，远端 ID 合并保留 UUID；顺延更新日期，离线分类改名可重试；账号归属隔离 pending/映射/删除队列，回切不重复；创建响应不明先核对，不盲目重复 POST |
| Habitica | Habits 的 +/−、Dailies 完成/取消、Role 信息及刷新；请求期间阻止重复操作，旧账号响应不得污染当前账号 |
| Habitica 选项 | 普通番茄与 combo 两种完成奖励各按自身开关独立执行；中断与真实延长超时各按自身开关计分；默认或自定义 Habit ID；短休息提醒不依赖是否延长；阶段换账号不向新账号错误计分；自定义 API 需 HTTPS 校验、凭据信任提示及禁止携凭据跟随重定向 |
| 声音 | 番茄结束音、休息结束音、环境音分别选择和调音量；只提供真实打包的资源；预听、暂停/结束时停止环境音 |
| 统计 | 保存每次完成时的实际专注分钟，不用当前设置反算旧记录；今日、总数/总时长、日均、近期图表、块及植物历史 |
| 专注复盘 | 7/30/90 个自然日，支持向前翻阅与按天查看块、植物及番茄记录；同一数据导出字节一致，Android 旧版缺失的实际分钟保持未知 |
| 任务专注 | 今日未完成任务可直接开始番茄；暂停保留任务与时长快照，放弃或跳过清除快照；按完成自然日记录用时，按任务 ID 汇总并支持独立 CSV |
| 单日专注明细 | 每条任务番茄显示开始时的标题、开始时间及记录分钟。跨午夜仍归入完成日，开始日不同时显示日期。缺少开始时间的记录排在末尾。 |
| 进程恢复 | Apple 恢复进行中或已暂停的专注。冷启动时按原截止时间补记已到期的番茄，历史写入中断后重试按同一次专注去重。历史提醒和 Habitica 请求不重放。Android 使用本机计时快照恢复 |
| 重置与清理 | 重置当前块同时清当前及当天块计数；与清空全部块/植物历史区分；番茄统计单独清理，不意外删 Task；破坏性操作需确认 |
| 旧数据兼容 | 新设置缺字段时使用默认值，不因为解码失败覆盖旧数据；保留本机离线任务、旧历史和已有植物文件 |

## 日界与存储

- **Task** 使用逻辑日：第一个时间块起点为日界，默认 04:00。午夜后但未到日界仍属于前一任务日。
- **番茄统计、时间块与植物** 保留现有自然日（`yyyy-MM-dd`）规则。不得为统一文案而重新归档已有记录。
- Mac/iPhone 使用用户授权的同一 iCloud Drive 父目录。Top 3 合并当前设备可见的修订，按日和 UUID 合并，并发删除优先于编辑。iCloud 文件实际送达、离线设备同步和重签仍需设备验收。
- 共享同一目录的 Mac 与 iPhone 应使用同一版本。3.1.1 新增了识别已记账专注的字段，更早的客户端写回历史时可能丢弃该字段，影响重试去重。3.0.0 之前的版本写回历史时还会丢弃任务专注明细。
- Android 的设置、专注/块/植物历史存本机；Habitica 只承担其已有的任务/打卡云端通道，**不能将功能一致表述为三端本地历史已同步**。
- 不在源码、产物或验证日志中写入个人账号凭据；Android 含 Token 的设置文件排除备份与换机迁移。

## 平台专属交互（不计为缺少业务功能）

| 平台 | 保留的原生能力与限制 |
|---|---|
| macOS | 菜单栏状态、桌面窗口、键盘快捷键 |
| iOS | 触屏导航、系统本地通知、回前台校时；后台暂停执行时不能承诺实时网络计分 |
| Android | 前台服务通知及通知栏控制；系统提醒受通知权限、电池策略和系统调度影响 |
| Web | 页面内提示，可选浏览器通知；块开始提醒只在页面打开时发出，休眠后补记计时但不补发提醒 |

## Web 客户端

`web/` 下的浏览器客户端为 3.2.0，与原生端使用同一套业务规则与记录格式。设置、计时快照、Top3、番茄统计、日块进度、块达标历史和植物沿用原生 JSON 字段，存在 `localStorage` 的同一个 v2 键中，一次写入。v1 数据迁移后原键保留不动。无法解析的数据或由更新版本写入的数据只读不覆盖。共享场景 `parity/logical_day.json` 与 `parity/focus_review.json` 由 `web/*.test.mjs` 直接读取校验。

| 模块 | Web 状态 | 说明 |
|---|---|---|
| 番茄计时 | 已对齐 | 暂停、继续、放弃、跳到休息，组合与阶段快照规则同原生。刷新或休眠后按原期限依次结算专注、休息和延长，不会创造新专注 |
| 休息 | 已对齐 | 手动或自动开始，空闲时可自选 1/5/15/30 分钟，延长为 0 不算超时，可暂停 |
| 时长设置 | 已对齐 | 取值范围同原生。新用户默认值同原生；旧 Web 用户保留原有时长 |
| 时间块 | 已对齐 | 块的数量、时段（分钟级，可跨午夜，起止相同表示全天）、目标、块任务和预计番茄，并标出当前块。时间落在两块之间时归入刚结束的块 |
| 时间块奖励 | 已对齐 | 每天每块只记一次达标，奖励一次，可给出休息建议。开始前提醒和冲刺提醒只在页面打开时显示 |
| 种植 | 已对齐 | 灌木、枯萎、树和空槽规则同原生，与日块进度分字段保存 |
| Task | 已对齐 | 3/3/不限，可改名分类，昨天只读，未完成任务顺延并留归档副本。编辑只改标题（旧 Web 的改分类入口已移除） |
| Task 云同步 | 已实现，未实测 | 按 Apple 规则移植：严格日期/分类备注、tag 对应分类、创建前持久化尝试并核对、删除墓碑、离线改名重试、各账号队列隔离。只在本页连接期间运行。账号以哈希标识，本地不存 User ID。改名分类只重写已同步的 todo；迁移来的旧任务不会自动上传 |
| Habitica | 已实现，未实测 | 习惯 +/−、每日打卡、角色与刷新。请求期间防重复，旧连接的响应不采用。凭据只在页面内存 |
| Habitica 选项 | 部分对齐，未实测 | 完成、组合、放弃、延长超时和块奖励各按开关计分，只计给阶段开始时的账号，刷新后不补发。支持默认或自定义 Habit ID 和私信提醒。不支持自定义 API 地址：CSP 只允许连接 `habitica.com` |
| 声音 | 已对齐 | 结束音、休息结束音与环境音可分别选择、调音量和试听，只列出 `web/audio` 中打包的文件，另有合成提示音。栖时场景从同站私有目录读取 |
| 统计 | 已对齐 | 记录实际分钟，提供今日、全部历史、日均、近期图表、块和植物历史 |
| 专注复盘 | 已对齐 | 7/30/90 天、翻页、单日明细。CSV 与原生逐字节一致，不加 BOM |
| 任务专注 | 已对齐 | 从今日任务或计时卡开始，快照、按 ID 汇总与任务 CSV 同原生。旧 Web 记录只有任务标题，按标题唯一对应任务 ID，无法对应时生成稳定 ID，开始时间记为未知 |
| 单日专注明细 | 已对齐 | 开始时间倒序、跨日显示日期、未知开始时间排最后、每次显示五条 |
| 进程恢复 | 已对齐 | 计时快照与历史在同一个键中原子写入，番茄按专注 ID 去重。多标签页共用锁，读后再写。迟到的提示音和通知不重放 |
| 重置与清理 | 已对齐 | 重置当前块计数、清空块记录与植物、清空番茄统计分开提供，都需确认 |
| 旧数据兼容 | 已对齐 | 缺字段用默认值，逐条丢弃坏记录。v1 迁移后原键保留，旧标签页之后新增的记录按 ID 补入一次 |

Web 不提供菜单栏、系统通知、前台服务、iCloud 目录和小组件。Habitica 在线流程（todo 同步、计分、账号切换）只有离线模拟测试，尚未用真实账号验证。

## 最终验证要求

- macOS 两种架构构建及打包、iOS Simulator 构建、Android Debug 构建均需实际执行。
- 使用隔离存储/专用模拟器检查暂停继续、休息延长、放弃/跳过、块数增减、任务编辑、种植持久化及统计分钟。
- Mac/iPhone 的新增共享数据文件必须接入文件夹发现、读取、重新加载和变更检测。
- 构建通过不等于真机后台与在线功能通过；没有真实测试账号时，Habitica 在线打分/导入/账号切换必须标为未实测。
- 真实设备的声音、锁屏通知和 iCloud 文件选择授权留给人工验收。遵循本项目偏好，不新增自动化测试框架。
