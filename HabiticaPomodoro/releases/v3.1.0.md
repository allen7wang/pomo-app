# Pomo 3.1.0 · 专注恢复

适用于 macOS build 21 和 iOS build 8。

从「任务」页或专注页开番茄后，应用会把当前专注存到本机。退出、系统回收或崩溃后重开应用：

- 进行中的番茄沿用原截止时间。已暂停的番茄保留剩余时间，可以手动继续。
- 任务 ID、开始时的标题、设置时长和组合进度随专注一起恢复。暂停后继续使用原时长计算进度环。
- 番茄在应用关闭期间到期时，启动后按截止时间所在的自然日补记，并按启动时的设置进入休息。历史结束音、通知及 Habitica 打卡不会重放。
- 专注页的今日分钟来自已保存的历史。更改番茄时长后，旧专注按实际记录的分钟显示。

计时快照存在本机应用目录，与启动时的数据目录绑定。Mac 和 iPhone 可以各自计时。切换数据目录后，已有专注要回到原目录才能继续。本机快照不携带 API Token，快照也不随 iCloud 专注历史传送。

重新打开应用时恢复的对象是尚未结算的专注。单独的休息倒计时在进程退出后结束。应用写入历史之前会清除计时快照，避免重复结算。若进程在清除快照后、写入历史前再次中断，该次记录可能来不及写入。
