# Pomo 3.2.0 · 单日专注明细

适用于 macOS build 23、iOS build 10 和 Android versionCode 9。

进入「专注复盘」，选中一天，在当日明细里展开「专注明细」。每次从任务开始并完成的番茄各占一行，最近开始的排在最上方。展开时先显示五条，可以继续查看更多。

每行显示开始时间、当时的任务名和计入历史的分钟数。任务中途改名，仍能看到那次番茄开始时的名称。跨午夜完成的番茄归入完成日，并在开始时间旁显示开始日期。

3.0.0 起保存的任务记录可直接查看。缺少开始时间的记录显示「开始时间未知」。普通番茄和只有每日总数的旧历史继续计入当日汇总。
