# Pomo 3.1.1 · 专注历史保存修复

适用于 macOS build 22 和 iOS build 9。

3.1.0 在写入历史前会清除计时快照。如果应用恰好在这两步之间退出，重新打开后会少一个番茄。3.1.1 会保留快照，直到番茄次数、专注分钟和关联任务明细成功写入历史。

如果历史暂时无法写入，应用会自动重试。已有本机快照的专注在下次打开应用时也能继续补记。若历史已经写好、快照尚未清除，应用会识别这次专注并跳过重复计数。普通番茄和从任务启动的番茄都适用。

时间块进度和种植记录各自保存。应用在更新这些文件时退出，可能会看到专注历史已经增加，时间块或花园进度尚未更新。冷启动补记时会跳过之前的提醒和 Habitica 打卡。

共用 iCloud 数据目录的 Mac 和 iPhone 应一起使用 3.1.1。较早版本写回同一份历史时，可能丢弃用于识别已记账专注的字段，影响重试去重。
