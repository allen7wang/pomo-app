# 专注番茄钟 Web · 3.2.0

浏览器版番茄钟，与 macOS、iOS、Android **3.2.0** 使用同一套业务规则和记录格式。版本号只在 `model.mjs` 的 `appVersion` 中定义，侧栏和设置页都读取它。各项对齐状态见 [FEATURE_PARITY.md](../HabiticaPomodoro/FEATURE_PARITY.md#web-客户端)。

- **计时**：开始、暂停、继续、放弃（组合清零）、跳到短休息（不计完成）。专注、休息和休息延长都按开始时的设置进行，换设置不影响已开始的阶段。短休息、长休息可手动或自动开始。空闲时可自选 1、5、15、30 分钟休息，不清已有组合。刷新或休眠后，到期的阶段按原截止时间补记，依次结算专注、休息和延长，不会自动开始新的专注。
- **时间块与种植**：1–24 块，每块 1–12 个番茄。时段精确到分钟，可跨午夜，起止相同表示全天。每块有目标、块任务和预计番茄。完成一个番茄种灌木，放弃或跳过记枯萎，完成一组另种一棵树。达标每天每块只记一次，重置当前块计数后也不重复奖励。本页打开时，在块开始前提醒，接近目标时提醒冲刺。
- **每日任务**：Work、MyOwn 每天各三件，Chores 不限。可改名分类、改标题、勾选、确认后删除。昨天的任务只读显示，未完成任务转到今天时，原日期保留一份归档。从任务开始的番茄记下开始时的标题、时长和时间。任务日以第一个时间块的开始为界，默认 04:00。番茄、时间块和种植按自然日统计。
- **专注复盘**：7、30、90 天，可向前翻页。选中一天，可看时长、任务用时、单日专注明细（按开始时间倒序，每次五条）、时间块和种植。可分别导出汇总 CSV 和任务用时 CSV，格式与原生端逐字节一致：UTF-8 无 BOM，CRLF 换行。清空番茄统计、清空块记录与植物分开操作，都需要确认。
- **Habitica**：凭据只保存在当前页面内存，请求直接发往 `habitica.com`，不跟随重定向。可查看角色、给习惯打分、完成每日打卡。连接期间，每日任务会同步为带日期和分类备注的 todo，分类对应 tag。只导入带这种备注的 todo。创建结果不明时先核对云端，不会盲目重复创建。番茄完成、组合、放弃、延长超时和块达标按各自开关计分，只记给开始该阶段时连接的账号，断开或刷新后不补发。
- **声音**：番茄结束音和休息结束音可分别选择、调音量、试听，可选合成提示音或 `audio/` 中打包的原生音效。环境音可选栖时随机场景或自定义环境音，只在专注时播放，暂停、休息或放弃即停止。栖时场景文件来自同一私有站点的 `../qishi-meditation-web/audio/`，不打包进本仓库。

## 数据与升级

全部数据保存在当前浏览器的 `localStorage`：

- `habitica-pomodoro-web:v2`：设置、计时快照、任务、番茄统计、时间块与种植记录。字段沿用原生 JSON 文件，统一写在一个键里，一次写入不会只写一半。
- `habitica-pomodoro-web:v1`：旧版数据。首次打开 3.2.0 时迁移到 v2，旧键原样保留，不修改也不删除。旧版仍开着的标签页之后新增的番茄和任务，下次加载时按 ID 补入，已经导入过的不会重复。

遇到无法解析的数据，或由更新版本写入的数据，页面只读运行，不覆盖原有内容。Habitica 账号在本地只以哈希标识，用来区分各账号的同步队列。

## 本地运行与测试

在 `web/` 目录启动静态服务器，然后打开 `http://127.0.0.1:8765/`。

```sh
python3 -m http.server 8765 --bind 127.0.0.1
node --test            # 业务规则、迁移、复盘与同步；共享场景读取 ../parity/
```

## 发布

运行包是把 `web/` 复制到 `workbench-runtime` 分支根目录。入口为 `project-management/private-web` 的 `habitica-pomodoro-web`，由统一工作台的 Google 登录保护。所有资源使用相对路径，无需构建，也没有第三方前端依赖。
